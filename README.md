## 📌 Project Overview

This project is a clean, responsive personal portfolio built with core web development technologies. It highlights my featured work, downloadable resume, certificates, and contact links.

### ✨ Features
- **Responsive Interface**: Works seamlessly across desktop, tablet, and mobile devices.
- **Interactive Scripting**: Driven by JavaScript (`script.js`) for dynamic UI interactions.
- **Resume & Certificates**: Direct links to view or download my resume and training certificates.
- **Contact & Social Links**: Easy access to my GitHub, LinkedIn, and email contact information.
